Getting Started

Welcome to OffDrop for Linux! Follow these steps to get started: Documentation


Installation and Setup

To install and use follow these steps:

  1. Download the latest release from github
  2. Run the Installer.
  3. Go to the downloads directory then unzip the folder.
  4. Run the application from the unzipped folder.


Running the Application

To successfully start using the application, follow these steps:

  1. Double click the start_application.sh file.
  2. Wait for it to Initialize..
  3. Once initialized, the application will be ready for use.
